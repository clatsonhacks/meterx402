Connect to ChatGPT

Use MeterX402 services in Custom GPTs with these simple steps:

1

Start ngrok

Expose your local MeterX402 connector to the internet:

ngrok http 3402
2

Copy your ngrok URL

Look for the "Forwarding" line in ngrok, something like: https://abc123.ngrok.io

3

Create a Custom GPT

Go to ChatGPT Custom GPT Editor

In the "Configure" tab, add actions with your ngrok URL as the base.

4

Add the OpenAPI spec

Import or paste the OpenAPI specification for MeterX402's connector API.

Connect to Claude Desktop

Add MeterX402 tools to Claude Desktop using MCP (Model Context Protocol):

1

Build the MCP server

From your MeterX402 directory:

npm run build
2

Configure Claude Desktop

Edit your Claude config file at: C:\Users\YOUR_USERNAME\.claude.json

Add the MeterX402 MCP server to the mcpServers section:

{
  "mcpServers": {
    "meterx402": {
      "command": "node",
      "args": ["A:/Hack/meterx402/packages/mcp-server/dist/index.js"],
      "env": {
        "HUB_URL": "http://localhost:4021",
        "BUYER_ACCOUNT_ID": "0.0.YOUR_ACCOUNT_ID",
        "BUYER_PRIVATE_KEY": "your_private_key_here",
        "BUYER_BUDGET": "1 HBAR"
      }
    }
  }
}
3

Restart Claude Desktop

Fully quit Claude Desktop (not just close the window - quit from the tray/menu bar) and reopen it.

4

Start a new chat

MeterX402 tools will now be available in any new conversation. Existing chats won't have them - MCP is loaded at session start.
